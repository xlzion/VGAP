# know–say gap 机制篇 · 无懈可击综合(2026-08-31 深夜)

跨 **2 数据集(R-Judge n=571 / A3S n=1150)× 3 宿主(Qwen2.5-7B / llama-3-8b / gemma-3-4b)= 6 格**,
每格多重控制。**结果只在本项目,独立于 NSCC。**

## ★★为什么(机制)——末层对"攻击标记"vs"事实"做相反操作

同模型、同 0-100 格式、同读出方向 d,只换判定对象,frozen-lens 末层(模型自己的输出读出):

| 概念 | lens 中层 | **lens 末层(输出)** | 末层做的事 |
|---|---|---|---|
| 注入(攻击/祈使) | 0.94/0.83/0.75 | **0.55 / 0.54 / 0.53** | **拆掉**读出(3 宿主) |
| URL(描述性事实) | 0.39(低) | **0.98 / 0.98 / 0.92** | **建起**读出(3 宿主) |

URL 的输出读出被**末层建起**(Qwen 0.39→0.98),注入的被**末层拆掉**(0.94→0.55)——**末层对两者做相反操作,三族一致**。
⇒ 丢弃是**主动、选择性**的:末层如实 surface 描述性事实、却压掉攻击标记。机制解释:**注入是祈使句,instruction-tuned 输出头去"顺应/处理"它(当指令),而非"上报"它(像 URL 当事实)**。base-vs-instruct 封顶进行中。

## ★最强口径——"模型算出来了、能说、却丢弃了"(不依赖已证伪的因果修复)

模型**中层就用自己的输出映射算出可读判定**(frozen 峰 0.90/0.83/0.75 @~40%,三族)→**末层丢弃到随机**(0.53)→只存活在激活(探针 0.97)→丢弃顽固:M2 prompt 修不掉、**G2 外科移除组件也修不掉(readout/verbal 回升~0,三宿主)**。R2 tuned-lens:Qwen tuned 峰 0.77 干净否偏转,两 lens 末层≈随机=输出抵消(3/3)。
**G2 因果封顶阴性=如实**:观察级对消真(过零假设)但不可 patch=压制顽固/分布式，**不主张单组件因果修复**；但最强口径不依赖它，反而 G2 阴性让"顽固丢弃"更硬。

## 可主张(经得起审)

1. **断链(chain-break)方向普适**:6/6 格 probe(激活探针)> 模型自身输出读出(lens_last / Step0)。
   Step0(末层真 logits 期望数字分)在 R-Judge 三宿主 ~0.53(随机)→ **No-Go A 否决**(gap 非解码假象)。
2. **不可 prompt 修复**:M2 三宿主 zero/CoT/few-shot 口头 best 0.55/0.63/0.63 ≪ 探针 0.96。
3. **机制 = 对消(Cancellation),现象真实**:frozen-norm DLA(逐例可加性 6 格 0.006–0.03✓)显示注入信号在部分组件对输出的贡献里(pos-only），却被反向组件抵消回随机(总 s 随机）。
   **pos-only 6/6 格过标签置换零假设**（真 0.60–0.67 vs null ~0.50）= 不是选择伪影。
   三选一：对消 ✅ / 淹没 ❌（去非判别方差不恢复）/ 偏转 ❌（零假设证明真有输出基里的正判别组件）。

## 诚实收窄（不能主张的）

- **强度非普适**：R-Judge 最强（gap 0.42、对消干净：pos 0.674→pos+neg 0.482）；A3S 弱（gap 0.10–0.23）；
  gemma 在 A3S 上 gap 仅 0.10（Step0 0.69 逼近"信息进 logits"）。**干净达标只有 R-Judge+Qwen 一格**，
  其余 5 格"方向对、强度弱"。→ 写"对消机制，R-Judge/Qwen 上干净，跨族跨集方向一致但较弱"，**不写"三族同强度/普适强对消"**。
- **不主张"主动/信号驱动压制"**：G1 观察级测（攻击内 c_peak→c_final 解耦）跨宿主不一致、gemma 测量坏（null corr 0.61）。
  区分"主动读信号再压制"vs"结构性对消"**观察级判不干净，须 G2 干预**。→ 不喊"模型看到注入才写反"。
- **不主张单组件因果修复**：B1 ablation 头条已 FAIL（且靶点曾被尺度混淆定错，见 `B_segment_verdict.md`）。
- **G2 因果封顶不跑**：方案门 = G0 跨 3 宿主同支；现严格只 Qwen → "门没过就不跑"。

## 方法链（为什么这次站得住，前两次不站）

- #1 raw-dsep（混淆幅度/判别力）→ 尺度伪影，已弃。#2 Cohen's-d（破坏可加性）→ 已弃。
- **#3 frozen-norm DLA**：可加性由构造保证，贡献大小与判别力两轴分开；再叠 **OOF**（去选择偏差）+ **置换零假设**（排伪信号）。三关全过。
